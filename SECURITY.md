# Security policy

Please don't report a security problem in a public issue or discussion.

## How to report

Either:

- **On GitHub:** open a
  [private vulnerability report](https://github.com/lpdfio/lpdf/security/advisories/new)
  on lpdfio/lpdf. Only Codesense can see it. Use it for a problem in any Lpdf
  repository.
- **By email:** write to [support@lpdf.io](mailto:support@lpdf.io) with
  `SECURITY` at the start of the subject line.

We aim to acknowledge a report within one business day, at any license tier,
including Community. Business hours are on the
[support page](https://lpdf.io/support).

Include what you can of:

- the Lpdf version, and which SDK or the VS Code extension
- what an attacker could do, and what they would need first
- the smallest XML, file or code that shows it

## What's covered

- The Lpdf engine, including license key verification, PDF encryption and
  permissions, and reading XML, fonts and images
- The SDKs for JavaScript, .NET, PHP and Python
- The VS Code extension
- The license portal at [my.codesense.dev](https://my.codesense.dev)

## Supported versions

Fixes ship in a new release of the latest minor version. Older minor versions
are not patched, so upgrade to get a fix.

## After you report

We tell you what we found and when a fix ships. With your permission, we credit
you in the release notes.
